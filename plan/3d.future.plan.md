# Scene Editor — পরিকল্পনা (Plan)

> অবস্থা: **শুধু পরিকল্পনা। কোনো কোড লেখা হয়নি।** মালিকের অনুমোদনের পর ধাপে ধাপে কাজ হবে।

## ১. কী চাই

Pacdora-র মতো একটা অভিজ্ঞতা:

1. **Scene:** 3D box একটা সাজানো পরিবেশে (গোলক, podium, পানি, দেয়াল) বসানো থাকবে।
2. **প্রতিটা object নিয়ন্ত্রণযোগ্য:** click করলে নীল bounding box আসবে, আর X / Y / Z gizmo দিয়ে সরানো, ঘোরানো, ছোট-বড় করা যাবে। শুধু box নয়, scene-এর জিনিসও।
3. **Box খোলা:** scene-এ বসানো box আমাদের Fold slider দিয়ে খোলা-বন্ধ করা যাবে। Pacdora-র scene-এ box শুধু বন্ধ অবস্থায় দেখা যায়, এখানে আমরা তার চেয়ে বেশি দিতে পারি।

> Pacdora-র scene, asset বা ফাইল **নেওয়া হবে না**। তাদের ToS মানা নিষেধ করে, আর প্রজেক্টের নিয়মও তাই। আমরা নিজেদের (বা CC0) asset ব্যবহার করব।

## ২. এখন কী আছে

| জিনিস | অবস্থা | কোথায় |
|---|---|---|
| একাধিক box (layout) | আছে | `apps/web/src/lib/scene-layout.ts` (`LayoutSpec`, `layoutInstances`) |
| Box বসানো ও মেঝের mirror | আছে | `carton-view.tsx` এর `placeLayoutOnly` |
| Fold slider | আছে, কিন্তু **সব copy একসাথে** খোলে | `preview-3d.tsx`, `portal/scene-3d.tsx` |
| Scene (পরিবেশ) | **নেই**, শুধু ধূসর background | |
| Object-এ click করে gizmo | **নেই**, পজিশন ফর্মে সংখ্যা লিখে বদলাতে হয় | |
| three-এর `TransformControls`, `GLTFLoader` | three-এ আছে, এখনো ব্যবহার হয়নি | `three/addons` |
| GLB export | আছে | `carton-view.tsx` `exportGlb` |

`carton-view.tsx` এখন ~১৬০০ লাইন। নতুন কাজ সেখানে ঢোকালে ফাইল আরও ফুলবে, তাই আলাদা module এ বের করা হবে।

## ৩. GLB কী (সংক্ষেপে)

GLB হলো 3D জিনিসের ফাইল (ছবির জন্য PNG-র মতো)। এক ফাইলে আকৃতি, রঙ/texture আর কোন object কোথায় সেটা থাকে। Blender থেকে *File → Export → glTF 2.0 (.glb)* দিয়ে বানানো যায়। three.js `GLTFLoader` দিয়ে সরাসরি পড়ে।

Scene পাওয়ার জায়গা: Poly Haven, Kenney, Quaternius (সব CC0), Sketchfab (শুধু CC0/CC-BY ফিল্টার দিয়ে), অথবা নিজে Blender-এ বানানো। ফাইল ১০–১৫ MB-র নিচে রাখা ভালো।

## ৪. ধাপসমূহ

### ধাপ ১: Selection ও Gizmo (box-এর উপর), admin

লক্ষ্য: Template Layouts (`p:a-layouts`) এ box-এ click করে টেনে সরানো।

- Click করলে raycast দিয়ে কোন box-এ লাগল ধরা। drag আর click আলাদা করা, নইলে camera ঘোরালেই select হয়ে যাবে।
- Select হওয়া box-এ নীল `BoxHelper` আর `TransformControls` (translate / rotate / scale)।
- Gizmo টানার সময় `OrbitControls` বন্ধ (`dragging-changed`)।
- **উল্টো হিসাব:** gizmo-র world position কে আবার layout-এর "box size" এককে ফিরিয়ে item-এর `x / y / z / yawDeg / pitchDeg / rollDeg` এ লেখা। এটাই কাজের কঠিন অংশ। `placeLayoutOnly` এর হিসাবের inverse লাগবে।
- ফর্মের সংখ্যার সাথে দুই দিকে sync (`onLayoutChange` callback)।
- **Repeat সমস্যা:** একটা item-এর `repeat.count` 5 হলে 5টা box। gizmo টানলে পুরো group সরবে। আলাদা করতে "Detach this copy" বাটন।
- মেঝের নিচে যাওয়া আটকানো (snap), undo/redo।
- Capture, icon আর GLB export এর সময় gizmo লুকানো।
- নতুন ফাইল: `viewer3d/gizmo.ts`। `carton-view.tsx` এ কম জায়গায় হাত দেওয়া।

### ধাপ ২: GLB Scene আনা

লক্ষ্য: admin একটা GLB scene upload করবে, প্রতিটা object select করা যাবে।

- `Scene` model (DB): নাম, `glbKey` (storage-এ ফাইল), সাইজ, active, sortOrder। Storage এখন LocalDisk। `LayoutSpec` (v3) এ `scene` field: কোন scene, আর object-ভিত্তিক সম্পাদনা।
- পুরনো (v1, v2) layout আগের মতোই পড়া যাবে (`readLayoutSpec` এ convert, legacy v1 এর মতো)।
- `GLTFLoader` + Draco/meshopt সাপোর্ট।
- **Selectable object:** GLB-র top-level node (বা নামওয়ালা group) এক একটা object ধরা। Click করলে ধাপ ১-এর মতোই নীল box আর gizmo।
- **Box-এর "slot":** GLB-তে `box_slot` নামের empty node থাকলে box সেখানে বসবে। না থাকলে মাঝখানে। একাধিক slot হলে একাধিক box।
- **সম্পাদনা save:** প্রতি object-এর position / rotation / scale, লুকানো/মোছা, রঙ বদল, node নাম ধরে `LayoutSpec` এ। মূল GLB অপরিবর্তিত।
- Upload নিরাপত্তা: আকার সীমা, ফাইল ধরন যাচাই (সার্ভারেও), শুধু super admin।
- Scene বদলালে geometry/texture dispose (memory leak আটকানো)।
- আলো ও shadow: GLB-র আলো আর আমাদের shadow plane / environment মিলিয়ে নেওয়া।
- নতুন ফাইল: `viewer3d/scene-loader.ts`, `server/scenes.ts`, admin UI `components/admin/scene-manager.tsx`।

### ধাপ ৩: প্রতি box আলাদা খোলা

লক্ষ্য: scene-এ কোনো box বন্ধ, কোনোটা খোলা।

- Item-এ `fold: 0..1` (optional; না থাকলে global slider মানবে, পুরনো layout ভাঙবে না)।
- আলাদা `fold` মানের জন্য আলাদা model বানানো, এক মানের সব copy clone করবে (সর্বোচ্চ ~৬টা আলাদা মান)।
- Select করা box-এ ছোট panel: "Open" slider।
- **Lid-only preset:** `hingeProgress` (hinge id → 0..1) আগেই আছে, তাই "ঢাকনা খোলা, বাকি বন্ধ" করা যাবে।
- `units`, `whole` bounds আর mirror এখন ধরে নেয় সব box একই আকারের। প্রতি variant ধরে মাপতে হবে।
- খোলা box-এও মেঝের উপর বসা ঠিক রাখা।

### ধাপ ৪: Portal ও capture-এ scene

- `p:tview` এর Sample tab এ scene সহ দেখানো (`portal/scene-3d.tsx`, `template-preview.tsx`)।
- Design sample ও icon capture-এ scene থাকবে।
- পুরনো capture (যেগুলোতে scene নেই) আগের মতো ধূসর background দেখাবে।

### ধাপ ৫ (ঐচ্ছিক, পরে ঠিক হবে): Customer নিজে সরাতে পারবে

- Customer তার ডিজাইনের box সরাতে পারবে কিনা, আর সেটা কোথায় save হবে (সেশন, নাকি project)।
- অনুমোদন ছাড়া শুরু হবে না।

## ৫. নিয়ম (সবসময় মানা হবে)

- Pacdora-র কোনো scene, texture বা ফাইল নেওয়া হবে না।
- আপনার (মালিকের) নিজের project, template বা layout-এর ডেটা অনুমতি ছাড়া বদলাব না। পরীক্ষা হবে আলাদা test ডেটায়।
- Commit/push হবে না, যতক্ষণ আপনি "commit and push" না বলেন।
- ব্রাউজারে না দেখে "চলছে" বলব না। admin login আমার কাছে নেই, তাই ব্রাউজারে দেখা অংশ আপনাকে মিলিয়ে নিতে হবে।
- বড় architecture বদলের আগে (যেমন storage সরানো, DB model) আপনাকে জিজ্ঞেস করব।

## ৬. ঝুঁকি

| ঝুঁকি | কীভাবে সামলাব |
|---|---|
| `carton-view.tsx` ফুলে যাওয়া | gizmo আর scene আলাদা module এ |
| ৪৮ box + পানি reflection + shadow মোবাইলে ভারী | quality fallback, আকার সীমা |
| Touch এ gizmo টানা বনাম page scroll | gizmo চালু থাকলে ওই canvas এ scroll বন্ধ |
| বড় GLB ফাইল | সীমা ~১০–১৫ MB, Draco/meshopt, পরে R2/S3 |
| GLB-তে mesh ভাঙা ভাঙা | node hierarchy দেখে object ধরা, দরকারে "group করুন" |
| আলো মেলে না | scene-এর আলো বন্ধ রেখে আমাদের environment বেছে নেওয়ার বিকল্প |
| পুরনো layout/capture ভাঙা | schema version, optional field, convert on read |

## ৭. আমি কীভাবে কাজ করব

1. **এক ধাপে এক কাজ।** ধাপ ১ শেষ হলে আপনাকে দেখাব, তারপর পরেরটা।
2. প্রতিবার `npx tsc --noEmit`, `npx eslint <paths>` আর `npx vitest run` চালাব। নতুন হিসাবের (inverse math, scene spec) জন্য unit test লিখব।
3. Test এর জন্য কোড দিয়ে একটা সরল GLB বানাব (কয়েকটা গোলক, podium, মেঝে)। আসল scene আপনি পরে দেবেন।
4. যা ব্রাউজারে দেখিনি, সেটা স্পষ্ট বলব: "ব্রাউজারে দেখিনি"।
5. Commit-এর মেসেজ ইংরেজিতে, ছোট, imperative।
